Clone the repository (only once)--use git bash


# Download the project to your computer
git clone https://github.com/Jen327777/InventoryManagementSystem

# Go inside the project folder(in gitbash)
cd InventoryManagementSystem

[optional:  first if it is visible na ba ang ang file na naclone nyo sa file explorer]


2. Create your own branch

# Create your branch and switch to it
git checkout -b

example: 

git checkout -b backend-brix      
git checkout -b frontend-raven     
```

Only run the command for **your** branch.
(make sure nasa branch niyo lang kau magpupush ,dont touch the main branch )

3. Work on your part and save your changes

[important github command]
# Check which files you changed
git status

# Add your changes
git add .

# Save them with a short message about what you did
git commit -m "Add products table"
```

4. Upload your branch to GitHub


-First push of your branch
git push -u origin database-gege   # replace w/ your own branch name

-next pushes, you can just use
git push
